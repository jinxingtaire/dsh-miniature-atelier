# 微缩工坊

在 DeepSeek Harness 里把创意做成可旋转、可交互的 3D HTML 作品。写一句话或上传参考图，检查和调整设计，再交给 DSH 会话制作。完成的 HTML 可以收藏、继续修改或下载。

四种制作类型包括场景创作、机械运转、拆解装配和微缩产线。机械、拆解和产线可以根据描述生成可编辑参数。未指定的数值是演示估算。每件作品的外观、运动和交互仍需实际预览和验收。

## 安装和首次运行

1. 安装 [DeepSeek Harness 桌面版](https://www.deepseek.com/harness/)。先使用实测版本 **0.2.2-rc.3** 和简体中文界面，方便使用原生会话的自动发送。包的兼容声明从 `0.2.2-rc.1` 开始，其他宿主版本与系统请以实测范围为准。
2. 从本仓库 GitHub Releases 下载 `dsh-external-dsh-miniature-atelier-0.24.19.tgz`，也可以复制这个 Release 附件的下载链接。
3. 在 DSH 侧栏打开「插件 → 添加插件」，填入 Release 附件链接或本地 `.tgz` 的绝对路径。安装并启用，根据宿主提示重新加载。侧栏出现「微缩工坊」即可打开。桌面版使用随附的运行时，安装插件时不用另装 Node.js、pnpm 或 Three.js。只从 GitHub 下载的源码归档需要先构建。
4. 在 DSH 登录自己的 **DeepSeek 账号**，确认普通 DSH 会话能回复。打开「微缩工坊 → 创作」，选择「机械运转」，输入：

   > 做一个持续转动的曲柄滑块模型，连杆带动滑块往复，默认 45 rpm，支持暂停和单步。

5. 等待自动填充，或点击「按描述填充」。确认 45 rpm 和运动关系，按需修改，再点「在 DSH 制作」。在新 DSH 会话中检查制作过程和最终文件；若自动发送受宿主语言或版本影响，用已复制的制作稿在普通 DSH 会话手动发送。
6. 完成后到「作品」刷新检索，找到成品后点击导入。打开预览检查交互，再按需下载 HTML。默认输出为 DSH **会话工作区**下的 `./miniature-runs`，可在制作稿编辑，最终以会话给出的实际路径为准。若要继续改，打开作品填写修改要求，生成新文件后再导入。

安装入口和支持的来源格式见 [DSH 插件管理器文档](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/client/ui-plugin-manager)。

## DeepSeek 连接与本机数据

| 功能 | 运行位置与条件 |
| --- | --- |
| 自动填参、创作意图、构思、提示词优化 | 通过 DSH 的 `llm` 服务调用 `deepseek-account / deepseek-flash`，使用宿主登录账号与对应额度。 |
| 参考图解读 | 图片上传后先保存在本机。插件在 DSH 启动独立分析会话，通过宿主的读图能力与同一模型服务解读；读图需要可用的模型连接和宿主文件工具。 |
| 制作与返修 | 在 DSH 原生会话中执行，使用该会话选用的模型、工具权限和工作区。制作稿会提供随插件打包的本机 Three.js r160 路径。独立 HTML 的浏览器验收取决于会话可用的工具。 |
| 编辑现有草稿、参考模板、现存成品 | 可在本机处理。已经自包含的 HTML 可用支持 WebGL 的浏览器离线打开。参考库的外链和远程案例封面需联网。 |

使用插件时无需填写插件专用 API Key，也无需部署后端。**只在 DSH 里配置 API Key 而未登录 DeepSeek 账号时，本版的自动填参、构思和读图仍使用账号通道。** 请登录账号，或使用手填参数、复制制作稿和原生会话的路径。Key 由使用者在宿主设置维护。

插件走 DSH 同源接口，`/api/miniature-atelier/design` 的 GET 检查插件路由是否就绪。路由就绪与模型账号、额度或网络状态分别检查。提示词、参考图观察等会参与相应的模型请求。参考图留在宿主本机数据目录，草稿和导入作品保存在客户端本地存储，制作文件保存在会话工作区。重要草稿和作品可下载备份。

## 排查

- **侧栏缺少微缩工坊**　检查插件安装在正在运行的 DSH 配置中并已启用，确认宿主版本，按提示重载。
- **模型调用失败或一直没有填参**　先用普通 DSH 会话确认登录、网络与账号额度，再点「按描述填充」重试。也可以选「使用手填参数」继续。
- **读图失败**　用小体积 JPEG 或 PNG 重试，检查宿主读图和写文件能力。仍失败时可以手动描述参考图。
- **会话中有 HTML，作品页没找到**　等待会话完成再刷新，搜索作品名或清空过滤；较早的会话可加载更多。也可以用会话 ID 手动导入实际的完整 HTML。
- **作品打开是白屏**　在浏览器检查 WebGL 与控制台，核对导入的是最终单文件 HTML。生成质量随需求和会话工具而变化。

## 从源码构建

插件的构建与测试仅使用 Node.js 标准库。插件元数据要求 Node.js 20 或以上。若另用 npm 运行宿主 `@deepseek-ai/dsh@0.2.2-rc.3`，该宿主要求 Node.js 24.9 或以上。桌面安装用户使用随附的运行时。

```sh
npm run build
npm test
npm pack
```

维护者可查看 [创作与修改流程](WORKFLOW.md)。反馈时请附 DSH 版本、操作系统、插件版本、复现步骤和脱敏后的报错。项目源码使用 [MIT](LICENSE)，第三方条款见 [第三方来源](THIRD_PARTY_NOTICES.md)。
